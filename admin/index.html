Admin / 管理后台

管理员 登录

这是 Mod 审核后台，只有站长能进。

第一次用？点这里

如果你从没设过账号，点下面的「设置第一个账号」， 填一个账号名和密码就能进后台 —— 密码只有你知道，服务器上只存加密后的哈希，不存明文。

已经设过账号却忘了密码：找站长用应急通道 （admin_key.txt 那把密钥）登录后，在「账号」页重设密码。

你不是站长：这个后台只给审核用，请去 Mod 仓库逛逛，或进常见问题。

登录成功后会在你这台设备的浏览器里记住，下次不用再输。

设置第一个账号

只有一个账号都还没有的时候才能这样建。 建完之后这里就失效了，只能由已登录的管理员在「账号」页添加。

用密钥登录（应急通道）

给没有账号的人用，比如密钥在手但账号还没设好。登录方式与账号登录完全等价。
