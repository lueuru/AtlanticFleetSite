参数页：调数值 ​

控制台第一页，也是用得最多的一页。 所有数值调整都在这里。

页面上有什么 ​

从上到下：

  1. 分组标题（可展开/收起）
  2. 参数行 —— 每行一个参数：名称、当前值、滑块
  3. 一键预设按钮（部分参数有）
  4. 粘贴导入分享码 按钮
  5. 恢复默认 按钮

怎么调一个参数 ​

基本操作 ​

拖滑块 → 数值实时变化。

倍率类参数默认 1.0：

  • 往右拖 = 增强（> 1.0）
  • 往左拖 = 减弱（< 1.0）

开关类参数默认 0：

  • 0 = 关闭
  • 1 = 开启

生效时机 ​

必须重开游戏

参数在游戏启动时读取一次。拖动滑块只改配置，不会立刻生效。

流程：调 → 完全退出游戏 → 重开 → 生效。

「完全退出」是从后台任务里划掉，不是按 Home 键。

分组管理 ​

参数按功能分组，方便找到你要的那个：

分组包含
战斗主炮、鱼雷、航弹、反潜
环境风的影响
感知声呐、雷达
航空舰载机
经济威望、修理
AI敌方反应
沙盒调试开关
联机本地热座
调试日志开关

展开 / 收起 ​

点分组标题展开或收起。展开状态会被记住，下次打开面板还是这个样子。

全部展开 / 收起 ​

页面上有「全部展开」「全部收起」按钮，一次处理所有分组。

为什么要记住展开状态

因为参数多，每次重开面板都从全展开开始，找东西很累。

记住状态之后，你可以只展开常用的那几个分组，其他收着。

一键预设 ​

某些参数提供快捷键，不用拖滑块：

场景典型预设
开局威望10 万 / 50 万 / 100 万
其他视参数而定

预设值都经过边界校验

一键预设的所有值都在硬边界内，不会出现「点了预设却没生效」的情况。

（手写 mod.json 才需要担心边界问题，见 功能接入总表。）

恢复本组 ​

每个分组可能带一个「恢复本组」按钮，把这个分组的所有参数还原成默认值。

比「恢复全部」更精细 —— 只想撤销某一组改动时用这个。

恢复默认（全部） ​

这是两段确认操作

点一次会进入「确认」状态，再点一次才真的执行。

而且切页或收起面板时，确认状态会自动清零 —— 防止你点了一次、去干别的、回来手滑点到第二次。

「恢复默认」会：

  • ✅ 把所有参数清空回默认值
  • ❌ 不会删除你装的 Mod

为什么 Mod 不会被删

因为操作对象不同：

操作影响
参数页「恢复默认」清空参数改动
Mod 页「删除」删掉Mod 文件夹

所以如果你装了 Mod A（它改了主炮伤害），点「恢复默认」后主炮确实回默认了，但下次重开游戏 Mod A 又生效了（因为 Mod 还在）。

想彻底停用 Mod，去 Mod 页 禁用它。

粘贴导入分享码 ​

这里是装别人 Mod 的主要入口。

  1. 点「粘贴导入分享码」
  2. 粘贴一串 AFMOD1:…
  3. 确认
  4. 完全退出游戏，重开

粘贴不进去怎么办

某些安卓设备对剪贴板有权限限制。可以尝试：

  • 长按输入框手动粘贴
  • 用「Mod 页」的分享码相关功能
  • 或者改用文件方式（丢进 mods/_sharein/）

详见 Mod 分享码。

当前值怎么读 ​

每个参数行会显示当前值。倍率类显示小数（1.5），开关类显示 0/1。

如果你不确定「这个值是不是我改的」，去 状态页 —— 那里会列出所有偏离原版的参数，对比更直观。

常见问题 ​

拖了滑块但没效果 ​

重开游戏了吗？ 这是最常见的原因。

数值会自动跳回去 ​

如果滑块拖不到你要的位置，说明那个位置超出了硬边界，被限制了。

看一下 功能接入总表 里这个参数的硬边界。

我改了很多，忘了改过什么 ​

去 状态页 看偏离清单。

想撤销一次改动 ​

  • 撤销一个分组 → 该分组的「恢复本组」
  • 撤销全部 → 「恢复默认」
