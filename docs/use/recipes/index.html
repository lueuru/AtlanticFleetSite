进阶：组合玩法 ​

把参数、舰船、编队组合起来，能做出一整套自己的游戏规则。本篇给几个现成的配方。

怎么用这些配方

每个配方是一份完整的 mod.json。

复制 → 在 mods/ 下新建文件夹 → 存成 mod.json → 重开游戏。

配方一：精准炮术流 ​

思路：靠「打得准」而不是「打得疼」变强。不破坏平衡，手感提升明显。

json
{
  "modName": "精准炮术",
  "author": "uruban",
  "version": "1.0",
  "combat": {
    "gun": {
      "spreadMul": 0.6,
      "accuracyMul": 1.25
    },
    "wind": {
      "shellsMul": 0.4
    }
  }
}

配方四：轻松养成 ​

思路：不肝、不缺钱，但保留养成的乐趣。

json
{
  "modName": "轻松养成",
  "author": "uruban",
  "version": "1.0",
  "economy": { "renownGainMul": 2.5 },
  "repair": { "timeMul": 0.5 },
  "ai": { "reactionMul": 0.8 }

组合的原则 ​

原则一：一次只改一类 ​

想改火力就集中改火力，想要经济就集中改经济。

一次改所有类，你会不知道是哪个起了作用。

原则二：先小后大 ​

先试 1.2，不够再加到 1.5。

直接拉到 5.0 再往回退，不如一步步往上加。

原则三：注意「双方对等」的参数 ​

参数对等？
torpedo.turnMul✅ 双方都变
sensor.sonarRangeMul✅ 双方都变
sensor.radarRangeMul✅ 双方都变
gun.damageMul❌ 只有你
air.wingSizeMul❌ 只有你

想要单方面优势，别用对等类的参数。

原则四：别忘状态页 ​

改完之后去状态页看偏离清单，确认改动符合预期。
