倍速与时间缩放 ​

这是全框架最容易让人困惑的一个功能。 单独用一篇讲清楚。

它是什么 ​

sandbox.timeScale 控制游戏时间的流速。

值效果
0暂停（所有东西冻结）
0.5慢放
1.0原版（默认）
2.0快进 2 倍
3.0快进 3 倍

它影响什么 ​

关键：它不只影响「动画」

时间缩放会同时作用于所有按时间推进的东西：

  • 开火动画、装填动画
  • 舰船机动
  • AI 的行动
  • 场景转场
  • 界面补间动画

所以它不是「播放速度倍速」，而是「整个游戏世界的节奏」。

最常见的困惑 ​

「为什么我点了发射，然后什么都没了」 ​

这是最常被报告的现象，而答案是：

你把倍速调得太高了。

发生了什么：

你按了发射 → 开火动画以 3 倍速播放 → 装填以 3 倍速完成 → AI 以 3 倍速行动 → 转场以 3 倍速播放 → 一瞬间就跳到了下一回合。

玩家的感受是「我点了发射，然后游戏就跳过去了」—— 好像什么都没有。

怎么办 ​

一句话解决

点悬浮窗旁边的倍速按钮，把它调回 x1。

那个按钮点一下循环：x1 → x2 → x3 → x1。

如果当前倍速不是 x1，按钮会显示警示色，提醒你现在不是正常速度。

怎么调倍速 ​

方式一：悬浮窗快捷按钮 ​

悬浮窗旁边的 x1 按钮，点一下循环。

快捷循环不含暂停档（x1 → x2 → x3 → x1），这是故意的。

方式二：参数页滑块 ​

「参数」页 → 沙盒分组 → 拖动 sandbox.timeScale 滑块。

这里**可以拖到 0（暂停）**和小数（如 0.5 慢放）。

为什么倍速不保存 ​

这是一个刻意的设计决定

sandbox.timeScale 只在本次运行有效。

下次启动游戏，它会强制回到 1.0。

为什么这么设计？

假设它被存进了设置文件：

  1. 你某次把倍速调到了 3.0
  2. 退出游戏
  3. 过几天再打开
  4. 发现「整个游戏都快得不正常」
  5. 但你完全不记得自己调过倍速
  6. 于是开始怀疑「游戏坏了 / Mod 出问题了」

这个体验很糟。框架的选择是：

宁可让你每次重新调，也不让你陷入「我不知道自己改过什么」的状态。

这是「实验性参数不跨会话持久化」原则的应用

同样的原则适用于所有危险性高、容易遗忘的参数。

参数每次启动回到安全默认值 —— 这是保证「你永远知道游戏处于什么状态」的基础。

为什么暂停档不进快捷循环 ​

快捷循环是 x1 → x2 → x3 → x1，跳过了 0。

原因：

误触到暂停 → Time.timeScale = 0 → 所有游戏协程冻结 → 游戏看起来完全死机了。

玩家的第一反应是「游戏挂了」，然后可能会强退、重装，甚至以为 Mod 搞坏了游戏。

所以不把暂停放在容易误点到的位置。

想用暂停，去参数页拖滑块（那里需要明确的操作动作，不容易误触）。

倍速的合理用法 ​

场景建议倍速
正常玩1.0（原版）
想快速过一遍战斗动画2.0
想看炮弹出膛的细节0.5
想暂停下来仔细看局势0（从参数页拖）
长距离航行等待2.0 – 3.0

建议：平时保持 1.0

倍速主要是「偶尔用一下」的功能。

如果一直开着倍速玩，会失去很多战斗的细节和紧张感 —— 而且更容易出现「我点了发射但什么都没了」的困惑。

和其他参数的关系 ​

倍速是唯一一个影响「节奏」而不是「数值」的参数。

参数类型影响
伤害、命中打得多疼
经济、威望赚得多快
时间缩放整个世界跑得多快
AI 反应敌人决策快慢（这是 AI 内部节奏，和全局时间是两回事）

timeScale 和 ai.reactionMul 的区别

容易混：

参数影响
sandbox.timeScale所有东西的时间流速（包括你自己的动画）
ai.reactionMul只影响 AI 决策的节奏

想「让敌人反应慢点」→ 调 ai.reactionMul。 想「整个游戏快进」→ 调 sandbox.timeScale。

排查清单 ​

遇到「游戏节奏不对」，按顺序检查：

  1. 倍速是多少 → 状态页会显示当前倍速
  2. 是不是 1.0 → 不是就调回 1.0
  3. 还是不对 → 看日志页有没有错误
  4. 怀疑参数问题 → 状态页看偏离清单
