术语表 ​

文档里出现的名词，一句话解释。按类别分组。

框架与 Mod ​

术语说明
Mod一个文件夹 + 一个 mod.json，用来改数值、加舰船、换模型。放在游戏私有目录的 mods/ 下
mod.jsonMod 的核心文件，UTF-8 无 BOM。里面写名号、舰船、编队、参数
参数框架统一管理的可调数值，目前 23 个，如 gun.damageMul
参数键参数的名字，形如 组.动作（gun.damageMul）
倍率参数改的不是绝对值而是「原值 × 倍率」，1.0 = 原版
软边界 / 硬边界软 = 滑块推荐范围；硬 = 框架接受的绝对范围，超出会被静默截断
priorityMod 加载顺序，越小越先加载。同值时按名字排
挂钩（hook）在游戏源码里插一段我们的代码

游戏内界面 ​

术语说明
小u游戏内的半透明悬浮窗（作者署名）。点它开控制台面板
控制台「小u」点开的界面，6 个标签页：参数 / Mod / 存档 / 日志 / 状态 / 帮助
收起成小圆点把「小u」缩成一个很小的点，基本不挡视线
三指手势三指同时按住屏幕，强制唤起「小u」（防收不到抬手事件）
倍速游戏时间快慢（x1/x2/x3）。仅本次会话有效，重启回 x1
偏离清单「状态」页里列出所有当前值 ≠ 默认值的参数

游戏内机制 ​

术语说明
威望 / Renown游戏内的货币，用来解锁舰船
舰级（class）一类船，如「Bismarck」。下面可挂多艘具体舰只
classID舰级的内部编号。等于它在数组里的下标，由框架自动算
舰种代号BB 战列 / CA 重巡 / CL 轻巡 / DD 驱逐 / SS 潜艇 / CV 航母 等
编队（fleet）一次「自定义战斗」里的舰船组合
热座对战同一台手机上两人轮流操作。不是联网对战
刺猬炮 / Hedgehog一种反潜武器（前置发射的深水炸弹）
乌贼炮 / Squid另一种反潜武器
深水炸弹 / Depth Charge反潜用的炸弹

技术名词 ​

术语说明
DLL游戏的核心程序文件（Assembly-CSharp.dll），这个框架会把它整个重编译一遍
重编译把 DLL 反编译成源码 → 加代码 → 再编译回去（不是运行时织入）
Assembly-CSharp.dllUnity 游戏的主程序 DLL，本项目重编译的目标
AssetBundle / .unity3dUnity 的资源包格式，用来装自制模型
不压缩打包UncompressedAssetBundle。必须，否则 Android 上读不了
prefabUnity 里的「预制件」，一个完整的可用对象（如一整艘船）
组件 / component挂在 prefab 上的脚本，如 Vessel / DamageSystem
CGI 式 #US 堆DLL 里存「用户字符串」（界面文本）的区段，UTF-16 编码
#Strings 堆DLL 里存「类型名」的区段，UTF-8 编码
落盘把数据写进文件，重启后还在
try/catch异常兜底——出错就记日志然后继续，绝不崩游戏

相关平台 ​

术语说明
Mod 仓库网页版作品集散地：https://atlanticfleet.asia/mods/
分享码AFMOD1:xxxx 格式的字符串，编码了一整个 Mod，用来互传
_sharein放分享码 .txt 文件自动导入的目录
AFMOD_profile.json玩家本地档案（代号 / 威望 / 战绩）
AFMOD_settings.json面板上改的参数覆盖值（实验性参数不跨会话）
AFMOD_log.txt落盘的运行日志，游戏关掉也不丢
