快速开始 ​

本篇带你从零装好，并完成第一次「改数值 → 看到效果」。全程在手机上完成，不需要连电脑。

三步走 ​

第一步：安装 带 Mod 框架的版本 ​

下载试装包，装到安卓手机上：

final_full_cn_MOD_v1.apk
1

装之前先备份存档

框架本身不会破坏存档，但任何改动游戏的做法都建议先备份。存档在手机的：

Android/data/<游戏包名>/files/rncampaignInfo.dat
1

把它复制出来一份放着就行。

详细安装步骤（含「未知来源」权限、覆盖安装、空间不足的处理）见 安卓手机安装。

第二步：启动游戏，找到「小u」 ​

进游戏后，屏幕边缘会出现一个半透明的圆形悬浮窗，上面写着「u」。这就是控制台入口。

  • 点一下它，打开控制台面板。
  • 如果没看到，试试三根手指同时按屏幕（这是强制唤起的兜底手势）。
  • 面板默认停在「帮助」页，那里有每个页面的说明。

还不熟悉怎么操作？看 悬浮窗操作技巧。

第三步：改一个参数，看效果 ​

  1. 点悬浮窗打开面板 → 切到「参数」页。
  2. 找到「战斗 → 主炮伤害」这一组，拖动滑块，把它从 1.0 调到 1.5。
  3. 关掉面板，完全退出游戏再重开（参数在启动时读取）。
  4. 进一场战斗，开一炮 —— 伤害明显变高了。

恭喜，你已经完成第一次 Mod。

想立刻看到「偏离原版」的清单？

面板 → 「状态」页，那里会列出所有被你改过、且当前值不等于原版默认值的参数，一眼看全你动过什么。这是排查「我怎么感觉数值不对」最快的地方。

三种上手路径 ​

刚接触这个框架，按你的目标选一条路走：

你的目标走这条路
只想把数值调爽参数页：调数值 → 参数系统
想装别人做的 Mod安装 Mod 的三种方式 → Mod 页
想自己做 Modmod.json 完整规范 → 发布到仓库
想加自己的船 / 模型自定义舰船 → 自制模型
玩出问题了出问题了怎么查 → 日志页

三个最常用的操作 ​

① 调数值 「参数」页 → 拖滑块 → 重开游戏生效。倍率类默认 1.0，开关类默认 0。

② 装别人的 Mod 「参数」页 →「粘贴导入分享码」→ 粘贴一串 AFMOD1:… → 自动落盘 → 重开游戏。

③ 自查问题 「日志」页 → 按「告警」「错误」筛选 → 点「复制全部日志」→ 发给作者。
