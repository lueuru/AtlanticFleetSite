制作 AssetBundle 模型 ​

想给舰船换或加一个自己做的外观，不用重打包 APK——只要导出一个 .unity3d 模型包丢进 Mod 目录就行。这一页讲怎么做。

原理：为什么必须挂组件 ​

游戏内的船不是「一个网格」，而是「网格 + Vessel + DamageSystem + 一堆脚本」的完整 prefab。框架加载你的模型时，是把它当作一个能直接 Instantiate 的船来用。

所以你的模型包必须包含完整的舰船 prefab，而不是光秃秃的 mesh。

最省事的做法

在 Unity 里复制一份游戏内置的 ships/<某条船> prefab，然后只替换它下面的网格模型。这样组件、碰撞体、挂点全都是现成的。

第一步：准备 Unity 工程 ​

  1. 用与游戏相同或相近的 Unity 版本（本工程目标是 Unity 4.7，2015 年版）。
  2. 建一个空工程。
  3. 导入或重建一条舰船 prefab，确保它带有：
    • Vessel（舰船主体逻辑）
    • DamageSystem（损伤分区）
    • 网格 / 材质 / 碰撞体
  4. 把要替换的网格换成你的模型，调整朝向与缩放，让它和原船朝同一个方向（通常是 +Z 或 -Z，对准原船朝向即可）。

第二步：导出 AssetBundle（关键） ​

用一段 Editor 脚本导出：

csharp
using UnityEditor;

public class ExportShip
{
    [MenuItem("AFMod/Export Ship Bundle")]
    static void Export()
    {
        Object[] assets = { AssetDatabase.LoadAssetAtPath("Assets/Ships/BismarckX.prefab", typeof(GameObject)) };
        BuildPipeline.BuildAssetBundle(
            null, assets,
            "Assets/Output/bismarckX.unity3d",
            BuildAssetBundleOptions.UncompressedAssetBundle,   // ★ 必须
            BuildTarget.Android
        );
        AssetDatabase.Refresh();
    }
}

必须「不压缩」打包

BuildAssetBundleOptions.UncompressedAssetBundle 不能省。

Android 上框架用的是 AssetBundle.CreateFromFile，它只能读不压缩的包。压缩包会加载失败 → 回退内置模型（表现为「我的模型没生效，船变成原版的样子了」）。

第三步：放进 Mod 目录 ​

有两种方式：

方式 A：放在 models/ 子目录（推荐） ​

mods/我的Mod/
├── mod.json
└── models/
    └── bismarckX.unity3d      ← 文件名（去掉扩展名）自动成为别名

文件名即别名——bismarckX.unity3d 的别名就是 bismarckX，不需要额外登记。

方式 B：在 mod.json 里显式登记 ​

想放任意路径、或想起好名字，用 modelBundles：

json
{
  "modelBundles": {
    "myships": "models/bismarckX.unity3d",
    "other": "D:/我的模型/foo.unity3d"
  }
}

第四步：在舰船里引用模型 ​

json
"ships": [
  {
    "class": "BismarckX",
    "type": "BB",
    "model": "@myships:BismarckX"
  }
]

  • @包别名:资产名 —— 简写形式（推荐）。
  • 或分开写："modelBundle": "myships", "modelAsset": "BismarckX"。

其中「资产名」= 你导出时那个 prefab 的名字（BismarckX）。

三档兜底：出错也绝不让游戏崩 ​

情况表现
包能加载、资产存在✅ 用你的自制模型
包缺失 / 损坏 / 压缩了⚠️ 回退到同舰种的内置模型，游戏照常跑
连回退都没有⚠️ 该船不可见，但记一条日志，不影响其他船与启动

自查：模型到底加载了没 ​

游戏内「小u」→「Mod」页底部有模型包自检，会列出所有已登记的 .unity3d：

  • 文件在不在
  • 是否已加载成功
  • 文件大小

配合「日志」页看有没有加载失败的具体原因。

常见问题 ​

现象原因解决
船变成内置船的样子包压缩了 / 路径写错用 UncompressedAssetBundle 重导；核对 models/ 文件名
船看不见资产名不匹配、prefab 缺组件核对 @别名:资产名；检查 prefab 是否带 Vessel 等组件
朝向 / 缩放不对prefab 没对齐原船在 Unity 里把模型调到与原船一致
