舰船与编队定义 ​

mod.json 里的 ships[] 和 fleets[] 两个数组，分别对应「新造一艘船」和「新排一支编队」。这一页给出每个字段的完整说明。

一、自定义舰船 ships ​

数组里每个对象是一支舰级（一个 class，下面可以挂多艘具体舰只）。

json
"ships": [
  {
    "class": "Example Class",
    "type": "BB",
    "nation": 0,
    "tons": 45000,
    "belt": 14, "turret": 16, "deck": 6,
    "guns": 8, "caliber": 15.0,
    "speed": 30,
    "renown": 320,
    "aircraft": 0,
    "instances": ["Example", "Example II"],
    "model": ""
  }
]

字段表 ​

字段类型说明
classstring舰级名。必须唯一，编队里靠它引用，也用于按名查内置模型
typestring舰种代号：BB 战列舰 / BC 战列巡洋舰 / CA 重巡洋舰 / CL 轻巡洋舰 / DD 驱逐舰 / SS 潜艇 / CV 舰队航母 / CVE 护航航母 / TB 鱼雷艇 / DC 护航驱逐舰 / HK 猎潜艇
nationint0 = 盟军，1 = 轴心。影响阵营与可用舰种
tonsint吨位
beltint舷侧装甲
turretint炮塔装甲
deckint甲板装甲
gunsint主炮门数
caliberfloat主炮口径（英寸）
speedint航速（节）
renownint解锁所需威望
aircraftint载机数（航母用）
instancesarray该级下的具体舰只名，一艘或多艘
modelstring模型引用。留空 = 按舰种自动借内置同类船模型

扩展字段（可选，默认关） ​

除了上面这些，还有一组表示舰船特性的布尔/数值字段，多数有合理默认值，按需填写：

字段说明
displacement / length / beam / range尺寸与续航（展示与计算用）
secGunsNumber / secGunsCalibre副炮门数 / 口径
torpedoNumber / torpedoCalibre鱼雷管数 / 口径
primaryAmmo / secondaryAmmo / torpedoAmmo各类弹药基数
isCarrier / isAircraftCarrier / isEscortCarrier航母类标记
isMerchant / isSubmarine / isEscort商船 / 潜艇 / 护航标记
hasSonar / hasDepthCharges / hasHedgeHog / hasSquid装备标记（声呐 / 深弹 / 刺猬炮 / 乌贼炮）
hasBundleModel / modelBundle / modelAsset自制模型显式写法（见下）

关键机制：classID 由数组下标决定

框架往游戏内注入舰船时，classID 必须等于它在数组中的下标。所以：

  • 不要试图手写 classID——框架自动算。
  • 船坞是按数组 Length 遍历的，所以往数组里加一项，船坞里就多一艘船。

模型字段的三种写法 ​

写法例子效果
留空"model": ""按 type 自动借内置同类船模型，能正常出现在船坞
简写"model": "@myships:BismarckX"@包别名:资产名，引用自制 AssetBundle
显式"modelBundle": "myships", "modelAsset": "BismarckX"同上，分开写

三档兜底（绝不崩）：① 包能加载且资产存在 → 用自制模型；② 缺失/损坏 → 回退同舰种内置模型；③ 连回退都没有 → 该船不可见但记日志，不影响其他船与启动。

二、自定义编队 fleets ​

数组里每个对象 = 一次「自定义战斗」的配置。

json
"fleets": [
  {
    "fleetName": "Example Fleet",
    "nation": 0,
    "ships": ["Example Class", "Bismarck"],
    "date": "1 September 1939",
    "timeofday": "Noon",
    "distance": 100
  }
]

字段表 ​

字段类型说明
fleetNamestring编队名
nationint0 盟军 / 1 轴心
shipsarray舰级名数组。内置名或自定义名均可
datestring日期，如 "1 September 1939"
timeofdaystring时段：Noon / Dawn / Dusk 等
distanceint交战距离
environmentstring可选，海况/天气
initiativeint可选，主动权归属
globalSpawnRotationfloat可选，全局出生朝向

解析规则 ​

  • 舰级名按名查 classID；如果按当前阵营找不到，会自动跨阵营再找一次。
  • 完全不存在的舰级 → 跳过该艘并记日志，不影响整支编队。
  • 第一支编队直接写进「自定义战斗」；多支会尝试克隆任务项追加，失败降级为只注入第一支。
