参数键全表 ​

这是框架全部 23 个可调参数的权威字典，数据直接来自源码 ModConfig.cs。手写 mod.json 时以本表为准。

怎么读这张表 ​

列含义
键名写进 mod.json 的名字
默认框架认为的「原版值」。倍率类通常是 1.0，开关类通常是 0
软范围滑块的推荐范围，日常调节落在这里
硬范围框架接受的绝对范围。超出会被静默截断
说明这个参数干什么

硬范围是静默的

写 "gun.damageMul": 99，而硬上限是 5 → 框架不报错，直接当 5 用。

这会造成「我明明写了 99 却只有 5 倍」的困惑。要么落在软范围内，要么别超硬范围。

感知与航空 ​

键名默认软范围硬范围说明
sensor.sonarRangeMul1.00.5–20–5声呐探测距离倍率

air.wingSizeMul1.00.5–20–4舰载机联队规模倍率

声呐和雷达其实是同一个距离源

原版游戏只有一个 visualRange 变量，声呐和雷达共用它。所以两个倍率是乘积关系作用在同一个值上——调其中任何一个都能「看得更远」。
