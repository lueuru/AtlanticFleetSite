发布你的 Mod 到仓库 ​

做好的 Mod 想让别人不费劲装上，把它发布到 Mod 仓库网页。别人在网页上搜到、点一下复制分享码，回游戏粘贴即可。

现在改成「网页上传」了

以前要用命令行跑脚本发布，现在直接在仓库网页上填个表传上去，等管理员过审就行。 完整流程见 → 上传你的 Mod（作者）

发布后的效果 ​

玩家打开仓库页：

  • 搜索 —— 按名字 / 作者 / 说明 / 标签搜
  • 排序 —— 最新 / 最热 / 名称
  • 看详情 —— 弹层显示完整说明 + 这个 Mod 改了哪些参数（自动从 mod.json 读出来，并标出调高 / 调低）
  • 复制分享码 —— 一点就复制，发 QQ / 微信最方便
  • 下载包体 —— 想手动装的人用

网页上传（推荐） ​

打开仓库页 → 滚到「把你的改装交上来」→ 填作者 → 拖入 mod.json（或直接粘 JSON）→ 点「提交审核」。

提交后进入待审核状态，管理员在后台点「通过」就上架了。

详细步骤与注意事项 → 上传你的 Mod（作者）

mod.json 至少要有什么 ​

json
{
  "modName": "我的超级 Mod",
  "author": "uruban",
  "version": "1.0",
  "description": "一句话说明",
  "tags": ["数值", "休闲"],
  "combat": { "gun": { "damageMul": 1.5 } }
}

系统会自动做的事 ​

后端收到你的包后会：

  1. 校验 mod.json 是否合法、能不能加载；
  2. 检查有没有重名（待审 / 已上架的同名会被拒）；
  3. 用内容哈希算出不冲突的别名（中文名也不会互相覆盖）；
  4. 过审后写进 packages/、生成 AFMOD1: 分享码、重建仓库清单。

常见退回原因 ​

原因怎么办
缺 modName补上名字再传
和已有 Mod 重名换个名字，或先让管理员下架旧的
参数超硬边界对照 参数键全表 改成合法值
内容重复（同一个包传了两次）改内容或删掉重复的那次
文件 > 32 MB正常 mod.json 只有几 KB，检查是不是放错文件了

写一个好的 Mod 页面 ​

仓库卡片的信息全部来自你的 mod.json：

想达到的效果怎么做
卡片显示作者写 author
卡片显示版本写 version
卡片显示一句话介绍写 description
能被搜到写 tags，或在描述里写关键词
详情页参数表准确参数按 参数键全表 的写法写

发布前自检清单 ​

  • [ ] mod.json 有 modName
  • [ ] 参数值没超参数键全表的硬边界
  • [ ] 舰级 / 编队名不太容易和别人撞
  • [ ] 文件大小 < 32 MB
  • [ ] 提交后（过审前）在后台待审能看到，过审后仓库里刷新能看到
