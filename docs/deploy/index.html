安装部署总览 ​

框架不需要服务器、不需要联网、不需要 Root。本质上就是换一个 APK 装上去。

但「怎么装」在不同场景下略有差别，本篇帮你选对路径。

先看一张表：你属于哪种情况 ​

你的情况走哪条路大概要做什么
第一次装，手机上没有这个游戏安卓手机安装下载 APK → 允许未知来源 → 安装
手机上已经有汉化版安卓手机安装直接覆盖安装（存档保留）
装完不知道文件在哪首次启动与目录进游戏，让框架自己建目录
想装别人给的 Mod安装 Mod 的三种方式分享码粘贴 / 放文件 / 网页下载
想自己改框架再打包从源码自己构建装 JDK + 跑一键脚本
不想用了卸载与还原卸载重装汉化版即可

一个前提说明 ​

框架分两个包，互不影响：

包名是什么要不要装
final_full_cn.apk纯汉化版（原样，不含 Mod 能力）已经有就不用动
final_full_cn_MOD_v1.apk汉化 + Mod 框架要玩 Mod 就装这个

两者不能同时装（同一个游戏的两个版本，包名相同会互相覆盖）。

覆盖安装不会丢存档

因为包名相同，安卓会把新版本覆盖到旧版本上，而存档在独立的数据目录里，不会被动。不过重大改动前还是建议备份一下（见 安卓手机安装）。

安装需要什么 ​

项目要求
系统安卓（Android 4.0 以上基本都能跑，游戏本体要求如此）
空间约 200 MB（APK 本体 ~88 MB + 安装后展开）
网络完全不需要。装完之后框架不联网
Root不需要
电脑不需要。官方推荐全程在手机上完成

内存要求

游戏本体对内存有一定要求。建议 8 GB 及以上内存的设备（或者至少 4 GB 且后台干净）。内存不足时最大的表现是进战斗后卡顿或闪退，这与 Mod 框架无关，是游戏本体的需求。

装完之后的推荐动作 ​

  1. 进游戏，确认能看到悬浮窗「小u」（看不到就三指同按强制唤起）。
  2. 打开面板 → 「帮助」页，花两分钟看看六个页面各干什么。
  3. 进「状态」页确认当前没有任何偏离原版的参数（说明装干净了）。
  4. 然后按 快速开始 改第一个参数试试。
