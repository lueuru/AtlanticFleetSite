卸载与还原 ​

不喜欢、出问题了、或者想回到纯净状态 —— 本篇讲怎么干净地退回去。

先想清楚你要回退到哪 ​

你想要的做法存档
不要 Mod 能力，但要汉化装回 final_full_cn.apk（覆盖安装）保留
要完全纯净，回到英文原版装回英文原版 APK需先备份
只是不想要某个 Mod在「Mod」页禁用它保留
只是不想要某几项改动在「参数」页「恢复默认」保留

大多数情况不需要卸载

如果只是不想要某个 Mod 或某项改动，根本不用卸载。

  • 单个 Mod：面板 → 「Mod」页 → 点「禁用」（保留文件，下次想用再启用）
  • 全部参数改动：面板 → 「参数」页 → 「恢复默认」（一键清空所有参数偏离）

这两个操作都比卸载安全得多，而且随时可以反悔。

场景一：退回纯汉化版 ​

想保留汉化，但不要 Mod 能力：

  1. 下载 final_full_cn.apk。
  2. 直接点击安装 → 系统会提示「已存在同名应用，是否替换」→ 确定。
  3. 安装后启动，悬浮窗消失 = 框架已移除。

存档不受影响。 你之前用框架改过的存档数据（比如改过的威望）会保留，因为存档是独立文件。

但改过的存档不会自动恢复

比如你用「存档页」把威望改成了 100 万，退回纯汉化版后威望还是 100 万。框架只负责改，不负责回滚。想恢复得在改之前自己记原值，或者用游戏自己的机制。

场景二：完全还原到英文原版 ​

  1. 先备份存档（重要）：

    Android/data/<游戏包名>/files/rncampaignInfo.dat
    1

    复制到别的地方。

  2. 卸载当前的游戏（设置 → 应用 → 找到游戏 → 卸载）。

    卸载会清掉数据

    卸载会连 Android/data/<包名>/ 一起删除。所以必须先备份。

  3. 安装英文原版 APK（eb3cdae*.apk）。

  4. 如果需要，把备份的存档放回原位置。

场景三：只清理 Mod 相关内容 ​

想保留框架，但把 Mod 文件清干净：

进入 Android/data/<游戏包名>/files/：

删什么效果
mods/ 下所有子文件夹所有 Mod 失效（等于回到无 Mod 状态）
AFMOD_settings.json面板设置重置（位置回默认）
AFMOD_log.txt历史日志清空
不要删 rncampaignInfo.dat这是游戏存档！

更安全的做法

删文件有风险（删错就麻烦）。建议改用面板操作：

  • 想清空所有 Mod → 「Mod」页逐个禁用或删除
  • 想清空所有参数改动 → 「参数」页「恢复默认」
  • 想重置整个框架 → 「Mod」页底部「重置整个 Mod 系统」（保留你自己的自制 Mod）

场景四：框架本身出问题了 ​

如果游戏因为框架而打不开或频繁闪退：

先自救（可能只是某个 Mod 的配置有错）：

  1. 如果还能进游戏：面板 → 「Mod」页 → 逐个禁用，找出问题那个。
  2. 如果完全进不去：用文件管理器把 mods/ 下的子文件夹临时改名（比如加个下划线前缀），框架就不会加载它们。能进游戏后再逐个排查。

还不行就覆盖安装：

装回 final_full_cn.apk，即可回到无框架状态，存档保留。

一个提醒 ​

框架对存档的改动只通过游戏自带的保存接口，不直接改文件字节。这意味着：

  • 改过的存档仍然是游戏能正常读的格式（不会因为格式不对而读不出）。
  • 但改动是永久的 —— 框架不回滚，需要你自己在改之前记录原值。

「存档」页里改威望/回合之前，建议先看一眼当前值（页面上会显示），心里有个数。
