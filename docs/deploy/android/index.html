安卓手机安装 ​

本篇是安装的详细步骤，包含各种意外情况的处理。

一、准备 ​

1. 备份存档（强烈建议） ​

存档位置：

Android/data/<游戏包名>/files/rncampaignInfo.dat
1

用手机自带的文件管理器，或者「MT管理器」这类工具，把这个文件复制一份到别的地方。

找不到 Android/data 目录？

安卓 11 及以上，系统自带的文件管理器可能看不到 Android/data。解决方式：

  • 用第三方文件管理器（如 MT管理器），它会申请对应权限；
  • 或者用数据线连电脑，从电脑端复制。

2. 确认手机空间 ​

APK 本体约 88 MB，安装后还会展开占空间。建议至少留 500 MB 空闲。

查看方式：设置 → 存储。

3. 确认包名冲突 ​

如果你手机上已经装了：

  • 纯汉化版（final_full_cn.apk）
  • 英文原版（eb3cdae*.apk）

先卸载英文原版

如果你装的是英文原版，需要先卸载它再装 Mod 版（如果两者签名不同，覆盖安装会失败）。纯汉化版则可以直接覆盖。

二、安装 ​

步骤 1：把 APK 传到手机上 ​

任意方式都可以：数据线、网盘、聊天软件传文件。

步骤 2：允许「未知来源」 ​

安卓默认不允许安装非应用商店的 APK，需要手动允许：

  • 安卓 8 及以上：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选择你用来打开 APK 的那个应用（文件管理器 / 浏览器）→ 允许。
  • 安卓 7 及以下：设置 → 安全 → 未知来源 → 勾选。

步骤 3：点击 APK 安装 ​

用文件管理器找到 APK，点击 → 安装。

如果提示「已存在同名应用，是否替换？」→ 选确定（这是覆盖安装，存档会保留）。

步骤 4：首次启动 ​

安装完成后点「打开」，或从桌面图标进入。

三、覆盖安装时的注意事项 ​

情况会不会丢存档说明
纯汉化版 → Mod 版不会包名相同，属于升级
旧版 Mod → 新版 Mod不会同上
英文原版 → Mod 版可能会如果提示签名冲突必须先卸载
卸载后重装会卸载会清掉数据目录

卸载前一定要备份

卸载应用会连数据一起删掉。 如果一定要卸载，先把 Android/data/<包名>/files/ 整个目录复制出来。

四、常见安装问题 ​

「解析包时出现问题」 ​

通常原因：

  1. 下载不完整 —— 重新下载一次，确认文件大小是 ~88 MB（不是几十 KB）。
  2. 安卓版本太低 —— 游戏本体要求安卓 4.0+。
  3. APK 被安全软件改过 —— 关掉安全软件的「安装拦截」再试。

「应用未安装」 ​

  1. 签名冲突 —— 手机上已有一个签名不同的同包名应用。先卸载那个，再装。
  2. 空间不足 —— 清理空间到 500 MB 以上。
  3. 系统限制 —— 部分定制系统（如某些国产 ROM）需要额外开启「允许安装外部应用」。

「存储空间不足」 ​

清理相册与聊天软件占用的缓存，或卸载不用的应用。安卓需要「安装包大小 + 展开大小」的空闲空间。

安装后打不开 / 秒退 ​

进战斗前就秒退，通常是内存不足。尝试：

  1. 关机重启，清空后台。
  2. 关掉其他占内存的应用。
  3. 如果还是不行，说明设备内存确实不够（游戏本体需求，与框架无关）。

如果是进战斗后闪退，看 出问题了怎么查。

五、装好后的验证 ​

进游戏，按顺序确认：

  1. 能看到悬浮窗「u」→ 框架已加载。
  2. 点开面板，切到「状态」页。
  3. 状态页应该显示没有任何参数偏离原版。

如果这些都正常，说明装干净了。接下来去 首次启动与目录 了解框架在磁盘上建了什么，或者直接去 安装 Mod 的三种方式 装第一个 Mod。
