这是什么 ​

简介 ​

大西洋舰队 Mod 框架 是给手机游戏《大西洋舰队》（Atlantic Fleet）用的。装上以后，改游戏不用连电脑。

它把原本「要手改文件、要连电脑、改错了游戏打不开」的 Mod 折腾，变成手机上点几下就能完成的事：拖滑块调数值、管理已装 Mod、改存档、看日志自查，全程不需要连电脑，也不需要懂 JSON。

无论你是想把主炮调强一点、加一艘自己画的船、让威望涨得快些，还是做一整套 Mod 分享给朋友，这个框架都能覆盖。

它和「汉化」是两回事

它是基于汉化版《大西洋舰队》做的，但与汉化定版是相互隔离的两个包。汉化定版（final_full_cn.apk）保持原样不受影响；Mod 框架单独产出一个试装包 final_full_cn_MOD_v1.apk。装了 Mod 框架 = 汉化 + Mod 能力，不装就是纯汉化。

Mod 是什么（别想窄了） ​

Mod ≠ 改数值 + 加船。 任何装进这个框架、能改变游戏内容的作品都算 Mod：

类别你可以放什么
参数改装火力、鱼雷、传感器、经济、AI、航空的数值调整
自定义舰船自己定义的舰级、武器、搭载
自定义编队编队编制、阵型、出击规则
模型 / 贴图3D 模型（AssetBundle）、涂装、图标等美术资源
音频 / 语音音效、语音、背景音乐
界面 / 皮肤界面配色、字体、图标、布局皮肤
剧本 / 战役关卡、剧情、任务
文本 / 翻译术语表、命名替换
工具 / 脚本辅助工具、批量脚本
整合包把上面几类打包成一键安装

也就是说：别人做的舰船模型、贴图、音效、界面皮肤、战役剧本，都可以单独传上来分享，不必硬塞进"改数值"里。仓库页顶部有分类筛选，可以按类型找。

它能做什么（框架提供的能力） ​

能力一句话说明
参数调节23 个参数，覆盖火力、鱼雷、传感器、经济、AI、航空。滑块直接拖
自定义舰船定义自己的舰级、属性、武器、搭载，让原版没有的船出现

存档编辑改当前战役的威望和回合，安全写盘
诊断与日志日志落盘、三级分级、一键导出、状态探针

快速开始 ​

三个入口，按你的情况选：

  • 我只想调数值 → 读 安装部署，装好后直接进 参数页。
  • 我想装别人做的 Mod → 读 安装 Mod 的三种方式，或直接去 Mod 仓库。
  • 我想自己做 Mod → 读 mod.json 完整规范，做完看 发布到仓库。

它是如何实现的 ​

一句话：重新编译了整个游戏主程序，在关键位置挂上框架的钩子。

游戏原本是 Unity 4.7 + Mono 编译出来的 Assembly-CSharp.dll。框架的做法是把它反编译还原成源码，在火力计算、模型加载、存档读写等位置插入请求转发，再重新编译回去。所以它不是一个外挂式的补丁，而是和游戏长在一起的改动 —— 这也是为什么它必须打包成完整 APK 而不是一个插件文件。
