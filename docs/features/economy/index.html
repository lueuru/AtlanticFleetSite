经济与威望 ​

威望（Renown）是《大西洋舰队》里的主要资源，用来买船、修船、解锁新内容。本篇讲怎么调节经济节奏。

参数 ​

参数键默认软边界硬边界说明
economy.renownGainMul1.00.5 – 5.00 – 100威望获取倍率
repair.timeMul1.00.5 – 2.00 – 5玩家舰船修理时间倍率
sandbox.startRenown00 – 1000 – 500新战役额外起始威望（千）

术语：威望 = 威望 = Renown

游戏内这个词有时译作「威望」、有时「威望」，指的是同一个东西（Renown）。框架文档里统一用「威望」。

三个参数分别管什么 ​

economy.renownGainMul —— 赚得快不快 ​

战斗胜利、完成任务获得的威望量。

  • 2.0 = 收入翻倍 → 攒舰队速度明显变快
  • 5.0 = 五倍 → 基本不缺钱

这是长期节奏参数，适合想快点体验后期内容的人。

repair.timeMul —— 修船等多久 ​

受伤的船需要时间修理。这个值控制修理耗时。

  • 1.0 = 原版
  • 0.5 = 修理时间减半
  • 0 = 立即修好（等同 sandbox.instantRepair）

想省事就调这个

repair.timeMul: 0 是「修船不要等」的效果，比反复点「立即修理」舒服。而且它是持续性的，不用每次手动点。

sandbox.startRenown —— 开局送多少 ​

开新战役时额外给的威望，单位是千。

设定值实际效果
0关闭（默认）
50开局多 5 万威望
100开局多 10 万威望

只对新战役生效

这个参数只在创建新战役时起作用。已有的存档不会因为你改了它就突然多一笔钱。

想在现有存档里加威望，去 存档页 直接改（那里是直接改当前战役的威望）。

两套思路：调收益 vs 直接给钱 ​

思路用哪个适合
慢慢变富economy.renownGainMul想保留养成乐趣，只是不想太肝
直接起飞sandbox.startRenown + 存档页想直接玩后期内容

推荐组合

如果你只是「不想太肝」，用这一套最舒服：

json
{
  "modName": "轻松养成",
  "economy": { "renownGainMul": 2.5 },
  "repair":  { "timeMul": 0.5 }
}

收入翻 2.5 倍 + 修船时间减半。每天打两三局就能稳步推进，不会因为缺钱卡住，也不会因为钱太多失去目标感。

注意事项 ​

大倍数会让游戏失去挑战

renownGainMul 调到 10 以上，你会很快买光所有船、修船不心疼，游戏的资源管理乐趣就没了。

建议先试 2.0 – 3.0，感觉还慢再往上加。这个参数随时可以改，不用一次到位。

现有的存档怎么加威望 ​

startRenown 只对新战役生效。现有存档想加威望：

面板 → 「存档」页 → 用「威望」那一栏的加减按钮，或者一键设值。

那里改的是当前正在进行的战役，改完点「保存到存档」即可。详见 存档页：改威望与回合。
