自制模型（AssetBundle） ​

用自己的 3D 模型替换或新增舰船外观。本篇讲怎么打包、怎么放、怎么引用。

先看这一条

这里不搬别家游戏的模型（不扒别人的模型），那有版权风险。

本篇讲的是你自己做的模型 —— 你自己建模、自己打包、自己用。

一句话流程 ​

你的 3D 模型（.fbx / .obj …）
      ↓ 用 Unity 导出
.unity3d 文件（AssetBundle）
      ↓ 放进
mods/<你的Mod>/models/
      ↓ 在 mod.json 里引用
完成

关键前提：必须「不压缩」打包 ​

这是最容易踩的坑

框架用的是 AssetBundle.CreateFromFile，这个接口只能读不压缩的包。

打包时必须选 UncompressedAssetBundle。如果用了压缩，加载会直接失败。

第一步：准备模型 ​

你需要在 Unity 4.7（与游戏同版本）里操作。

  1. 导入你的模型文件（.fbx 等）。
  2. 调整材质和贴图。
  3. 把它做成 Prefab（预制体）。

模型规格建议

  • 坐标系：和游戏内现有舰船的方向一致（船头朝向要对）。
  • 缩放：参考游戏内同类舰船的大小。做太大或太小都会显得奇怪。
  • 材质：用游戏支持的着色器。用自定义着色器可能显示为粉色（着色器丢失）。

第二步：打包成 AssetBundle ​

在 Unity 里用脚本打包，关键是这个参数：

csharp
BuildPipeline.BuildAssetBundle(
    null,
    new AssetBundleBuild[] { /* 你的资产 */ },
    outputPath,
    BuildAssetBundleOptions.UncompressedAssetBundle,   // ← 关键：不压缩
    BuildTarget.Android
);

目标平台要选 Android

如果打包时选了 PC 平台，安卓上加载会失败。BuildTarget.Android。

产物是一个 .unity3d 文件（扩展名其实随意，框架扫的是 *.unity3d）。

第三步：放进游戏 ​

在 Mod 目录下建 models/ 子目录，把包丢进去：

mods/
└── 我的模型Mod/
    ├── mod.json
    └── models/
        └── 曙光号.unity3d

最省事的地方：文件名自动成为别名

框架会自动扫描 models/ 目录，把每个 .unity3d 文件的文件名（去掉扩展名）登记为别名。

所以 曙光号.unity3d 的别名就是 曙光号，你不需要在 mod.json 里写任何 modelBundles 配置。

第四步：在 mod.json 里引用 ​

在舰船定义里用 modelBundle 和 modelAsset 指定：

json
{
  "modName": "我的模型Mod",
  "ships": [
    {
      "class": "曙光级",
      "type": "CA",
      "modelBundle": "曙光号",
      "modelAsset": "Shuguang_Prefab"
    }
  ]
}

字段填什么
modelBundle包别名 = 文件名（不含 .unity3d）
modelAsset包内Prefab 的资产名

modelAsset 是包内的资产名，不是文件名

打包时你给 Prefab 起了什么名字（比如 Shuguang_Prefab），这里就填什么。

填错的表现是日志里出现「包内找不到资产」。

三档兜底：模型找不到会怎样 ​

框架的加载顺序是逐级降级，永远不会因为没有模型就崩游戏：

顺序情况结果
1自制模型加载成功显示你的模型
2自制模型失败回退到同舰种的内置模型
3内置也找不到船不可见，但记日志，游戏照常运行

为什么这样设计

玩家自己做模型，出错是常态（压缩选项选错、平台选错、资产名写错…）。

如果错了就崩游戏，那体验很差。所以框架的选择是：宁可显示得不对，也不能打不开。

怎么检查模型有没有加载成功 ​

有两种自检方式：

方式一：面板里的模型自检 ​

「Mod」页底部，框架会列出所有已登记模型包的自检结果：

  • 文件在不在
  • 是否已加载
  • 大小（字节）

如果某个包显示「文件不存在」，说明路径或文件名不对。

方式二：看日志 ​

「日志」页会记录：

  • 自动登记了哪些模型包
  • 每个包加载成功/失败
  • 包内找不到资产时的具体名字

└── 曙光级模型包/
    ├── mod.json
    └── models/

常见问题 ​

船出现了，但显示成别的样子 ​

说明自制模型没加载成功，回退到了内置模型。检查：

  1. 包是不是不压缩打的？
  2. 平台是不是 Android？
  3. 别名对不对（文件名是否匹配）？
  4. modelAsset 名字对不对？

去「Mod」页看模型自检结果，或「日志」页看具体报错。

船完全看不见 ​

三级兜底全部失败了。通常是包的问题：

  • 包损坏
  • 资产类型不对（不是 GameObject/Prefab）

看日志里的详细报错。

模型显示成粉色/紫色 ​

这是 着色器（Shader）丢失的典型表现 —— 打包时用的着色器和游戏内的不一致。

解决：用游戏内已有的标准着色器重新打包。

模型方向不对 / 大小不对 ​

坐标系或缩放的问题。需要在 Unity 里调整后重新导出。

参考现有船

最笨但最有效的办法：把游戏内同舰种的船作为参照物，对比大小和朝向。
