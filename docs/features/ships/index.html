自定义舰船 ​

让游戏内出现原版没有的舰船：自己定义舰级名、属性、武器、搭载。

最小例子 ​

在 mods/我的船/mod.json 里：

json
{
  "modName": "我的船",
  "ships": [
    {
      "class": "曙光号",
      "type": "CA",
      "nation": 0,
      "cost": 250,
      "displacement": 12000,
      "length": 180,
      "beam": 20,
      "speed": 32,
      "range": 8000,
      "mainGunsNumber": 9,
      "mainGunsCalibre": 8.0,
      "torpedoNumber": 12,
      "torpedoCalibre": 24,
      "aircraft": 2,
      "hasSonar": 1,
      "beltArmor": 1.5,
      "deckArmor": 1.2
    }
  ]
}

重开游戏后，船坞里就会出现「曙光号」。

字段说明 ​

基本身份 ​

字段类型默认说明
class文本——舰级名，玩家在船坞里看到的名字
type文本DD舰种代号（见下表）
nation数字00 = 盟军（英），1 = 轴心（德）
cost数字100购买价格（威望）

舰种代号（type） ​

代号含义
BB战列舰
BC战列巡洋舰
CA重巡洋舰
CL轻巡洋舰
DD驱逐舰
SS潜艇
CV航空母舰
CVE护航航母
TB鱼雷艇
DC护航驱逐舰
HK猎潜艇

type 决定很多默认行为

它不只影响分类显示，还决定模型怎么挑、战斗里怎么表现。所以选准确很重要。

如果不确定自己的船算哪类，选一个最接近的现有类别。

尺寸与性能 ​

字段单位/含义默认
displacement排水量（吨）2000
length长度100
beam宽度11
speed最高航速30
range射程5000

武器 ​

字段含义默认
mainGunsNumber主炮数量4
mainGunsCalibre主炮口径（英寸）4.7
secGunsNumber副炮数量0
secGunsCalibre副炮口径0
torpedoNumber鱼雷发射管数8
torpedoCalibre鱼雷口径21

装甲 ​

字段含义默认
beltArmor舷侧装甲1.0
deckArmor甲板装甲1.0
turretArmor炮塔装甲1.0

装甲是倍率还是绝对值

按框架的实际处理，这些装甲字段是相对系数（1.0 是基准）。调高更耐打。

弹药与航空 ​

字段含义默认
primaryAmmo主炮弹药量200
secondaryAmmo副炮弹药量0
torpedoAmmo鱼雷弹药量8
aircraft搭载飞机数0

装备开关 ​

这几个用 1 = 有，0 = 没有：

字段含义
hasSonar有声呐
hasDepthCharges有深水炸弹
hasHedgeHog有刺猬弹
hasSquid有乌贼炮

术语说明

  • 刺猬弹（Hedgehog） —— 向前抛射的一排小型炸弹，需直接命中才引爆
  • 乌贼炮（Squid） —— 比刺猬弹更晚出现的反潜迫击炮，可设定引爆深度

舰种类别标记 ​

这些通常由 type 自动决定，一般不用手写：

字段含义
isCarrier是航母
isAircraftCarrier是舰队航母
isEscortCarrier是护航航母
isMerchant是商船
isSubmarine是潜艇
isEscort是护航舰

舰名列表 ​

字段说明
instances该级的舰名数组。留空则用舰级名代替
json
"instances": ["曙光号", "晨曦号", "暮光号"]
1

这样「曙光号」这个舰级就有三艘船，分别叫这三个名字。

模型（高级） ​

字段说明
modelName复用内置模型资源名。留空则按 type 自动挑
modelBundle模型包别名（配合 models 段使用）
modelAsset包内的 prefab 资产名

详见 自制模型（AssetBundle）。

常见问题 ​

加了船但船坞里没有 ​

  1. 检查 class 是否为空 —— 空的舰级名不会被创建。
  2. 重开游戏了吗 —— 舰船在启动时注入。
  3. 看日志 —— 「日志」页会有加载记录，失败会写原因。

船出现了但看不见模型 ​

模型没有正确加载。框架的兜底顺序是：

  1. 自制模型（如果你配了 models）
  2. 回退到同舰种的内置模型
  3. 不可见，但记日志

所以你至少应该能看到一艘长得像该舰种的船。如果完全看不见，看日志里的模型加载记录，详见 自制模型。

舰船名字和现有舰级重名了 ​

框架会记录一条告警（「Mod 页」顶部会显示冲突计数），但不阻止加载。后加载的会覆盖先加载的。

详见 Mod 冲突排查。
