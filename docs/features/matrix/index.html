硬边界是静默的

如果你手写 gun.damageMul: 99，而硬边界是 5，框架不报错，直接当成 5。

这会造成「我明明写了 99 却没效果」的困惑。 所以：

  • 面板拖滑块 → 永远在范围内，不会遇到这问题
  • 手写 mod.json → 对照本表的「硬边界」列

双方对等的参数 ​

标了「双方对等」的参数，调高后敌人也一起受益：

参数为什么对等
torpedo.turnMul鱼雷的物理特性对双方一样
sensor.sonarRangeMul声呐是硬件能力，敌方也有
sensor.radarRangeMul同上

想要单方面优势

调伤害或命中类参数 —— 那些只影响你的武器表现。

或者用环境类参数（如 wind.shellsMul 调低），那是改变整个战场的规则。

保留字（写在 mod.json 里必须用英文原值） ​

字段可用值
timeOfDayNoon / Dawn / Dusk / Night
type（舰种）BB / BC / CA / CL / DD / SS / CV / CVE / TB / DC / HK
nation0（盟军）/ 1（轴心）

这些值不能翻译

框架和游戏用这些字符串做匹配。写中文会导致识别失败。
