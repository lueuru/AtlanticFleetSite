上传你的 Mod（作者） ​

做好一个 Mod，想让别人一键装上？直接在仓库网页上把它传上去，等管理员过审，就会出现在仓库列表里，所有人都能搜到、复制分享码、下载。

不用命令行、不用发给人代传，打开网页填个表就行。

发布后的效果 ​

玩家打开仓库页，能对你的 Mod：

  • 搜到 —— 按名字 / 作者 / 说明 / 标签搜
  • 看详情 —— 弹层显示完整说明 + 这个 Mod 改了哪些参数（自动从你的 mod.json 读出来，还会标出每一项是调高还是调低）
  • 复制分享码 —— 一点就复制，粘到任意聊天窗口就能发出去
  • 下载包体 —— 想手动装的人用

三步上传 ​

第一步：打开仓库页，滚到「把你的改装交上来」 ​

地址是仓库主页往下的上传区。也可以点右上角的「上传 Mod」按钮直达。

第二步：填信息和文件 ​

  • 作者 —— 填你的名字 / 昵称。别人在仓库里看到的就是这个。

  • 联系方式（可选） —— 万一审核要问你，方便联系。

  • mod.json 内容 —— 两种方式，任选：

    方式怎么做
    拖文件把你的 mod.json 拖进虚线框，或点框选文件
    贴文本直接把 JSON 文本粘到下方文本框

    两种都行；拖了文件后再手改文本会以文本为准。

第三步：点「提交审核」 ​

提交后会提示「已提交，等待管理员审核」。这时候还没上架 —— 要等管理员在后台点「通过」才会出现在仓库里。

什么样的 mod.json 能过审 ​

只要能正常在游戏内加载，基本上就能过。具体：

  • modName 必填，没有名字的包会被直接拒。
  • 建议把 author、version、description 都写上，仓库卡片显示得更好看。
  • 参数值别超出参数键全表里的硬边界——超了会被游戏静默钳制，实际效果和你写的不一样（这是最难查的坑）。
  • 大小上限 32 MB（正常 mod.json 也就几 KB）。

一个最小的例子：

json
{
  "modName": "我的超级 Mod",
  "author": "uruban",
  "version": "1.0",
  "description": "一句话说明你这个 Mod 干了什么",
  "tags": ["数值", "休闲"],
  "combat": { "gun": { "damageMul": 1.5 } }
}

审核会看什么 ​

会看不会看
mod.json 格式是否合法、能不能加载你的 Mod 好不好玩
有没有重名（和已有的撞名会被退回）你的 Mod 是不是原创
内容有没有明显问题你的 Mod 强度是否平衡

过审 → 自动上架，生成分享码，所有人可下载。 被驳回 → 会附一句原因，改完可以重新传。

上传后想改？ ​

现在还没有「在线改」的功能，重新传一份新的就行：

  1. 在 mod.json 里把 version 改高（比如 1.0 → 1.1）；
  2. 再走一遍上传流程。

重名规则

同名（modName 相同）的包如果是待审 / 已上架状态，会被拒。所以：

  • 想更新自己的 Mod → 先联系管理员把旧的下架，或换个名字传；
  • 纯粹想测试 → 名字里加个「测试」字样，避免和正式版撞。

上传前自检清单 ​

  • [ ] mod.json 有 modName
  • [ ] 参数值没超硬边界（对照 参数键全表）
  • [ ] 舰级 / 编队名不太容易和别人撞
  • [ ] 文件大小 < 32 MB
  • [ ] 提交后在仓库里刷新，能看到自己的 Mod（过审后）
