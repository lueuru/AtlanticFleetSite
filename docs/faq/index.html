常见问题 ​

按「你现在遇到什么」来找答案。

装了没反应 ​

Q：我改了参数 / 装了 Mod，进游戏发现没变化。

A：九成是没重开游戏。框架只在启动时扫描一次 Mod 目录、读一次参数。改完必须完全退出游戏（不是切后台，是彻底关掉）再重开。

如果重开了还是没反应，按顺序查：

  1. 「Mod」页能不能看到你的 Mod？（看不到 = 位置放错了）
  2. mod.json 是不是直接丢在 mods/ 根目录了？（必须放在子文件夹里）
  3. 文件夹名是不是 _ 开头？（_ 是系统保留前缀，会被跳过）
  4. 「日志」页有没有相关错误？

悬浮窗「小u」找不到 / 点不动 ​

Q：屏幕上找不到「小u」，或者点了没反应。

A：

  • 可能被收起成小圆点了（半透明、很小）。在屏幕边缘找找，点圆点还原。
  • 三指同时按住屏幕可以强制唤起（这是为「部分机型收不到抬手事件」留的逃生通道）。
  • 桌面端可以直接按 F9 开关面板。

数值不对劲 ​

Q：感觉伤害/速度/什么的都变快了，像开了加速。

A：先看「状态」页的「偏离原版的参数」清单——它列出所有当前值 ≠ 默认值的参数。

重点怀疑 sandbox.timeScale（游戏倍速）。倍速参数不会跨重启保留，启动时强制回 1.0，所以正常重开一次就好了。

面板看不懂 / 按钮太多 ​

Q：控制台里一堆选项，不知道该动哪个。

A：打开「小u」→「帮助」页。那里是大白话、零英文术语的说明。首次安装会自动弹一次。

日常想快速上手：参数页 → 选一个「一键预设」（原版 / 硬核 / 爽快 / 快节奏）。

模型没生效 ​

Q：我做了自制模型，但船还是原版的样子 / 看不见。

A：按顺序查：

  1. AssetBundle 是不是用 UncompressedAssetBundle 不压缩打的？（压缩包读不了）
  2. 文件放对了吗？mods/我的Mod/models/xxx.unity3d
  3. model 写法对不对？"@包别名:资产名"
  4. 「Mod」页底部有模型自检，看文件在不在、有没有加载成功
  5. 「日志」页看有没有加载失败的具体原因

Mod 之间打架了 ​

Q：装了两个 Mod，好像互相覆盖。

A：这是正常现象。「Mod」页顶部会显示「检测到 N 处 Mod 间重名冲突」，点「日志」页能看到每条具体是哪两个 Mod。后加载的覆盖先加载的。

想控制谁赢：在 mod.json 里调 priority（越小越先加载）。详见 Mod 冲突排查。

战斗里「点了发射就没反应」 ​

Q：点发射按钮，然后什么都没发生。

A：先看一眼当前倍速。如果倍速不是 x1，先点回 x1 再试。

原因是 Time.timeScale 会同时管辖开火动画、装填、AI 行动、转场——倍速很高时，动画飞快推进，观感就像「一瞬间什么都没了」。

如果 x1 下依然异常，那就是真缺陷，请导出日志（「日志」页 →「复制全部日志」）反馈。

分享码怎么用 ​

Q：别人发了我一串 AFMOD1:...，怎么装？

A：

  • 在游戏内：「小u」→「参数」页 →「粘贴导入分享码」→ 重开游戏
  • 或粘进仓库网页的分享码解析器，先看清楚这是什么再决定装不装

不支持联网对战？ ​

Q：能和好友联网打吗？

A：不支持互联网联机。本游戏本体零网络代码，且这个框架是纯客户端重编译出来的，没法做服务器。

能做的是同设备热座对战——一台手机上两个人轮流操作（local.versus 开关）。详见 玩家档案与本地热座。

怎么彻底还原 ​

Q：我想把一切恢复成原版。

A：分三层，看你要还原到什么程度：

想要的效果操作
清掉所有参数改动「参数」页 →「恢复默认」（两段确认）
停用 / 删除某个 Mod「Mod」页 → 禁用或删除
重置整个 Mod 系统（保留自制 Mod）「Mod」页底部 →「重置整个 Mod 系统」
完全回到没有框架的原版卸载框架 APK，装回原版

日志在哪 / 怎么给作者看 ​

Q：出问题了要我提供日志，日志在哪？

A：「小u」→「日志」页 →「复制全部日志」，直接粘贴发给作者即可。

日志同时落盘在 <ModRoot>/AFMOD_log.txt，游戏关掉也不会丢。
